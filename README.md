# AŞK BEAUTY

Yerel site dosyası: `index.html`

Domain hazırlığı: `askbeautyexclusive.com`

Bu repo GitHub Pages ve `askbeautyexclusive.com` domaini için hazırlanmıştır.

Yerelde en sağlıklı kontrol:

```bash
python3 -m http.server 5173
```

Sonra tarayıcıda:

```text
http://localhost:5173/
```

Yayına alma için GitHub Pages aktif edilmeli ve DNS kayıtları domain sağlayıcısında GitHub Pages'e yönlendirilmelidir.

Instagram bio için önerilen hızlı bağlantı:

```text
https://askbeautyexclusive.com/links.html
```

Kısa bio metni önerisi:

```text
AŞK Beauty | Kalıcı Makyaj, Kaş & Kirpik, Cilt Bakımı, Tırnak
Randevu ve konum için linke tıklayın.
```

Instagram highlight önerisi:

```text
Randevu
Hizmetler
Galeri
Konum
Sertifikalar
SSS
```

Instagram gönderi linkleri hazır olduğunda `data/instagram.js` içindeki `postUrl` alanları güncellenebilir.
